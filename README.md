# My First React App

### Week 2 Guided Learning Activity

This project is a simple React application built with TypeScript and Vite.

The application demonstrates how to:
- Create a React application using Vite and TypeScript
- Create a custom React component
- Import and render a component in `App.tsx`
- Style a component using a separate CSS file

## Technologies Used

- React
- TypeScript
- Vite
- CSS
